# AsuraCraft — ฟอนต์ไทย สระไม่ลอย

Resource pack ของเซิร์ฟเวอร์ **AsuraCraft.net** แก้ปัญหาสระและวรรณยุกต์ไทยลอยผิดตำแหน่งใน Minecraft Java

เซิร์ฟส่งแพ็กนี้ให้อัตโนมัติตอนเข้าเกม ไม่ต้องโหลดเอง

## ทำไมสระถึงลอย

Minecraft วาดตัวอักษรทีละตัวแล้วเลื่อนปากกาไปตามความกว้างของตัวนั้น **ไม่มีระบบจัดวางตัวอักษร (text shaping)** เลย
ฟอนต์ของเกมเองให้สระ/วรรณยุกต์มีความกว้างจริง ๆ ปากกาเลยเดินผ่านพยัญชนะไปก่อนแล้วค่อยวาดสระ — สระจึงไปอยู่ข้าง ๆ แทนที่จะอยู่บน

ฟอนต์ไทยที่ทำมาดีแก้เรื่องนี้ในตัวฟอนต์เอง: สระ/วรรณยุกต์มีความกว้าง **0** และวาดถอยหลังมาเกาะตัวก่อนหน้า
**Kanit ทำแบบนั้นอยู่แล้ว** (สระอิ: ความกว้าง 0, left side bearing −481) แพ็กนี้จึงแค่ส่งฟอนต์ให้ ไม่ได้ดัดแปลงอะไร

## ในแพ็กมีอะไร

```
pack.mcmeta                       pack_format 88 (Minecraft 26.2) รองรับย้อนถึง 1.20.2
pack.png                          ไอคอน
assets/minecraft/font/default.json  ตัวตั้งค่าฟอนต์
assets/minecraft/font/thai.ttf      Kanit Regular
```

`default.json` มี 3 ตัวเลขที่ปรับได้:

| ค่า | ความหมาย |
|---|---|
| `size` | ขนาดตัวอักษร (ตอนนี้ 11 — ใกล้เคียงความสูงฟอนต์เดิมของเกม) |
| `shift` | `[แนวนอน, แนวตั้ง]` เลื่อนตำแหน่ง เพิ่มค่าที่สอง = ตัวอักษรลงล่าง |
| `oversample` | ความคม ยิ่งสูงยิ่งคมแต่กินหน่วยความจำมากขึ้น |

## สร้างใหม่

```bash
pip install fonttools pillow
python make_pack.py
```

เปลี่ยนฟอนต์ได้โดยวางไฟล์ `.ttf` ใหม่แล้วแก้ตัวแปร `SOURCE` ใน `make_pack.py`
ฟอนต์ที่เลือกต้องให้สระ/วรรณยุกต์มีความกว้าง 0 ไม่งั้นสระจะลอยเหมือนเดิม — สคริปต์จะเตือนถ้าไม่ผ่าน
